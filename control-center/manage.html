Security setup required before private launch

In Cloudflare Zero Trust, create a self-hosted Access application protecting highlineracingnetwork.com/control-center/* and allow only the owner's verified identity. Confirm unauthenticated visits are blocked, then test that other identities receive Access denied. GitHub repository permissions are a second independent barrier for publishing. If the domain is merely proxied to GitHub Pages, verify Cloudflare Access path protection actually applies before relying on it.

Phase 1 provides a centralized shortcut hub with real authenticated editing destinations. In-page editing forms, automatic commits, audit logging, and role management require a server-side API and should not be implemented with tokens embedded in JavaScript.
